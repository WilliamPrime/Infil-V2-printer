
# Breaky Belt

## What is Breaky Belt? 
Breaky belt is a belt printer that prints at an angle, in theory allowing infinetly long prints. That and the cross gantry are what i believe make it speciala.

Some of the printers that inspired me to make this are:
- [Baby Belt](https://github.com/RobMink/BabyBeltPro)
- [Annex K3](https://github.com/Annex-Engineering/Gasherbrum-K3)

## why is it called the Breaky Belt?
Originally it was going to be called the Belty Boi, however, when modeling it in fusion i kept encountering issues, so it got renamed to the breaky belt.
Dont worry though, hopefully it shouldnt break on you!

An alterative name i was considering was BRRRTT, pronounced Bert, it was supposed to mimic the sound the printer makes while printing quickly.

# building it
On the topic of it breaking on you (which hopefully it shouldnt do).
When building it, I would suggest you build the bed assembly first.And assemble it as shown in the following animation

https://github.com/user-attachments/assets/72ef6f26-8bf3-4d65-aa56-422cc91b3fcc

When building it you will find the CAD for the extruder is not included
the mounting holes for the extruder support anything with the same mounting as the sherpa mini
for my build im using the [ProtoXtruder 2.0 by Nhchiu](https://github.com/nhchiu/3DPrinter-Designs/tree/main/ProtoXtruder_2.0)

~1300g of primary colour
~600g of secondary colour
